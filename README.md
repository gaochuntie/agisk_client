## 简体中文  

### 项目简介  

欢迎来到 **GPT Partition GUI Manager** 项目！这是一个用于管理 GPT 分区的图形化工具，目前正在进行重构，以提供更专注的功能和更高效的用户体验。  

---

### 🚀 功能  

#### 计划改进  
- 🌟 **增强的 GPT 分区管理**  
  提供直观的图形界面来管理 GPT 分区。  

- 🌍 **多语言支持**  
  支持以下语言：  
  - 简体中文  
  - 繁体中文  
  - 英语  

- 🔧 **轻量化与模块化**  
  删除与 GPT 分区管理无关的功能模块，包括：  
  - 基于 XML 的磁盘和分区操作。  
  - XML 工具模块。  

---

## English  

### Project Introduction  

Welcome to the **GPT Partition GUI Manager** project! This tool provides a graphical interface for managing GPT partitions and is being restructured to focus exclusively on this functionality.  

---

### 🚀 Features  

#### Planned Improvements  
- 🌟 **Enhanced GPT Partition Management**  
  Intuitive GUI-based management for GPT partitions.  

- 🌍 **Multilingual Support**  
  Supported languages:  
  - Simplified Chinese  
  - Traditional Chinese  
  - English  

- 🔧 **Lightweight and Modular**  
  Removing unrelated features, including:  
  - XML-based disk and partition actions.  
  - XML tool modules.
